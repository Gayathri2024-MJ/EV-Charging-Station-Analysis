# EV Charging Station Utilization and Peak Hour Analyzer

## Project Overview
This project analyzes EV charging station data to understand charging patterns, station utilization, electricity consumption, and peak demand periods using Microsoft Power BI.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX

## Dashboard Pages

### Page 1 – EV Charging Station Overview
- Total charging sessions by charger type
- Total charging sessions by payment status
- Average charging cost by vehicle type
- Total electricity consumed by vehicle type
- Total charging sessions by vehicle type
- Total charging sessions by city

### Page 2 – Time & Demand Analysis
- Charging sessions by hour
- Charging sessions by day
- Charging sessions by month
- Charging sessions by station
- Peak charging hour
- Highest demand month
- Highest demand day

## Key Insights
- Peak charging hour: 6 PM
- Highest demand month: July (325 sessions)
- Highest demand day: Thursday (520 sessions)
- Highest station utilization: RS Puram EV Hub (462 sessions)
- Highest city usage: Pune (606 sessions)
